# 流程测试说明

## 一、系统架构概览

### 整体数据流

```
ADS1292 (心电采集前端)
  DRDY(PA3) --- EXTI中断 --> drdy_flag = 1
  SPI1(PA5/6/7) <-------> SPI读9字节
          |
          
main.c while(1) 主循环 (每10ms一次)
  1. ecg_camp_task()
     读取ADS1292 -> ch1/ch2_data -> flag=1
  2. HMI_TaskProcess()
     ecg_showwave_task()
       FIR滤波: S1(LPF 2Hz) / S2(BPF 5-40Hz)
       [算法采集钩子] 积累到算法缓冲区
       波形归一化(0-255) -> printf到串口屏
  3. HAL_Delay(10ms)
          |
          v (采集完成后)
身份注册 (5000点~20秒):
  Task_Identity_Registration()
    挂载SD -> 打开<name>.DAT
    循环10次: R波对齐 -> PCANet -> 写SD
身份认证 (1500点~6秒):
  Task_Identity_Authentication() -> return 0/1
    R波对齐 -> PCANet -> 读10模板 -> 曼哈顿距离 -> 投票
```

## 二、硬件资源分配

| 外设 | 引脚 | 用途 |
|---|---|---|
| SPI1 | PA5(SCK), PA6(MISO), PA7(MOSI) | ADS1292 心电采集 |
| SPI2 | PB10(SCK), PC1(MOSI), PC2(MISO) | SD 卡读写 |
| UART5 | (CubeMX默认) | 串口屏 TJC 通信 |
| UART7 | (CubeMX默认) | 天问语音助手通信 |
| GPIO | PA0(PWD), PA1(START), PA3(DRDY) | ADS1292 控制线 |
| GPIO | PA2(CS-ADS1292), PC3(CS-SD卡) | SPI 片选 |

## 三、HMI 串口命令协议

### 命令格式
通过 UART5(串口屏) 或 UART7(天问) 发送2字节命令(大端序,高字节在前):

| 命令 | 值(HEX) | 说明 |
|---|---|---|
| CMD_USER_VERIFY | 0x01 0x00 | 用户身份验证 |
| CMD_ADMIN_VERIFY | 0x01 0x01 | 管理员验证 |
| CMD_USER_REGISTER | 0x00 0x00 | 用户注册 |
| CMD_ADMIN_REGISTER | 0x00 0x01 | 管理员注册 |
| CMD_UNLOCK | 0x02 0x02 | 开锁 |
| CMD_SYS_INIT | 0x04 0x04 | 系统初始化 |
| CMD_MANAGE_USERS | 0x03 0x03 | 用户管理(预留) |
### 串口调试方法
连接 STM32 的调试串口(USART1或SWO), 使用串口助手或MDK Debug Viewer 观察 printf 输出。
所有 printf 输出的信息即为系统的运行日志, 关键步骤均有中文/英文说明, 可用于跟踪状态机执行过程。

## 四、测试流程

### 4.1 系统初始化

上电后自动执行:
- MPU -> HAL_Init -> SystemClock -> GPIO/SPI/UART/FATFS 初始化
- SPI_Init() 初始化CS引脚
- ADS1292_Init() + ADS1292_Set_start() 启动心电采集
- arm_fir_init_f32 初始化FIR滤波器 S1(呼吸)/S2(心电)
- HMI_Init() 初始化串口屏,发送PAGE_INIT

预期: 串口屏显示初始页面, printf输出初始化信息
**串口输出:**
```
[HMI] HMI模块初始化完成, 等待指令...
```

### 4.2 SD卡初始化测试 (SYS_INIT=0x0404)

发送 0x04 0x04 -> 调用 SD_Init_FATFS()

预期输出:
```
[HMI] Initializing SD card...
=== SD Card Init ===
SD OK - Total: XXXXX KB, Free: XXXXX KB
[HMI] System initialization complete
```

### 4.3 身份注册 (REGISTER)

1) 发送 0x00 0x00 (用户) 或 0x00 0x01 (管理员)
2) 输入用户名+回车 (如 testuser)
3) 等待约20秒采集5000个心电数据点
4) 自动执行 Task_Identity_Registration():
   10次R波对齐 -> 10次PCANet -> 写入 testuser.DAT

预期结果:
- SD卡生成 testuser.DAT (特征文件,约1.7MB) 和 testuser_RAW.TXT (原始数据)
- 串口屏显示 page r_s (注册成功)
**串口输出(完整流程):**

### 4.4 身份认证 (VERIFY)

1) 发送 0x01 0x00 (用户) 或 0x01 0x01 (管理员)
2) 输入用户名+回车 (如 testuser)
3) 等待约6秒采集1500个心电数据点
4) 自动执行 Task_Identity_Authentication():
   1次R波对齐 -> PCANet -> 读10模板 -> 曼哈顿距离 -> 投票

预期结果:
- 通过: 串口屏显示 page user_s / page adm_s
- 失败: 串口屏显示 page default
- printf输出投票结果 (如: Votes: 8/10 threshold: >4)
**串口输出(完整流程):**

### 4.5 开锁 (UNLOCK)

发送 0x02 0x02 -> 发送 unlock 字符串到天问 -> 5秒后回到IDLE
**串口输出:**
```
开锁
[HMI]   模拟: 向天问发送开锁指令, 电磁锁打开
[HMI]   模拟: 5秒到, 电磁锁自动关闭
```

## 五、关键参数 (task.h)

| 宏 | 值 | 说明 |
|---|---|---|
| SENSOR_WIN_LEN | 250 | AI模型输入窗口 |
| DISCARD_POINTS | 150 | 滤波器瞬态丢弃点数 |
| REG_RAW_POINTS | 5000 | 注册采集长度(~20秒) |
| AUTH_RAW_POINTS | 1500 | 认证采集长度(~6秒) |

## 六、常见问题排查

| 现象 | 可能原因 | 排查方法 |
|---|---|---|
| 无DRDY信号 | ADS1292未工作 | 检查PWD/START引脚,示波器看DRDY |
| SD卡挂载失败 | SPI2通信异常 | 检查CS=PC3,SCK=PB10,MISO=PC2,MOSI=PC1 |
| R波检测失败 | 信号质量差/增益低 | printf打印Output_data2看数值范围 |
| 采集不完成 | pcanet_sample_count不递增 | 检查ecg_showwave_task中算法钩子 |
| 注册/认证超时 | 采集循环未退出 | 检查HMI状态机SUB_ACQUIRE判断逻辑 |
| 所有模板FAIL | MATCH_THRESHOLD不合适 | 先打印一批距离值观察再调整阈值 |

## 七、快速测试流程

1. 上电
2. 发送 SYS_INIT(0x0404) -> 确认SD卡OK
3. 发送 REGISTER(0x0000) -> 输入 test -> 等待20秒
4. (摘掉并重新戴好电极)
5. 发送 VERIFY(0x0100) -> 输入 test -> 等待6秒
6. 查看认证结果,根据距离值调整MATCH_THRESHOLD
7. 多次注册不同用户验证区分度
